# Sign Reversal of the Peak Asymmetry in a Coupled RLC Circuit Swept Across an EIT Resonance

Elias Schlesinger, 2026. 

This repository holds the compiled paper manuscript.pdf. It studies the classical analog of electromagnetically induced transparency in two coupled RLC circuits when the two circuits are tuned to different frequencies, and shows how the two peaks around the transparency window trade prominence as the detuning changes sign.
